# E-Cell UIET KUK — Recruitment Task Submission 🚀

A responsive web application featuring the official portal for the **Entrepreneurship Cell (E-Cell), UIET Kurukshetra University**, alongside an interactive **Idea Submission & Selection Form**.
Task_1 : Idea Submission
Task_2 : E-CELL UIET KURURKSHETRA WEBSITE

---

## 📌 Overview

This project was developed as part of the technical hiring process for the E-Cell UIET Kurukshetra technical team. It includes:
1. **E-Cell UIET Portal**: A modern, mobile-responsive landing website highlighting initiatives, vision, and team activities.
2. **Idea Selection Form**: An interactive, user-friendly frontend form designed for students and budding entrepreneurs to submit startup ideas with seamless client-side validation.

---

## ✨ Key Features

* **Fully Responsive Design**: Optimized across mobile screens, tablets, and desktop displays.
* **Interactive Idea Submission**: Structured input fields (Idea Domain, Problem Statement, Solution, Team Details) with real-time UI feedback.
* **Modern UI/UX**: Clean layout, smooth transitions, and intuitive navigation reflecting E-Cell's brand identity.
* **Clean Code Architecture**: Modular components and well-commented source code for easy maintainability.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (Tailwind CSS)
* **Design & Icons**: Font Awesome / Lucide Icons / Google Fonts
* **Deployment**: GitHub Pages / Vercel / Netlify (*optional*)
